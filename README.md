# 🛠️ Sistema de Gestión para Taller Mecánico

## 01. ¿Qué problema resuelve?
Simplifica el registro y administración de servicios automotrices, facilitando la visualización de diagnósticos, cotizaciones y control de trabajo dentro de un taller mecánico a través de una interfaz moderna y accesible.

## 02. ¿Cómo lo construiste?
- **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+).
- **Herramientas de construcción:** Vite / Create React App, Git, GitHub.
- **Decisiones técnicas:** Se estructuró la aplicación mediante arquitectura basada en componentes reutilizables para separar la lógica de negocio del diseño de la interfaz, gestionando el estado dinámico de los servicios prestados.
